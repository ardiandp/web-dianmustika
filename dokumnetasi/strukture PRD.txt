Prinsip utama project

Saya akan memasukkan aturan ini ke PRD:

1. SEO First

Setiap halaman harus bisa memiliki:

SEO title
meta description
canonical URL
Open Graph
structured data bila relevan
heading hierarchy
alt text
SEO-friendly URL
2. Performance First

Hindari:

library JS yang tidak diperlukan
carousel berat
video autoplay
gambar original berukuran besar
font terlalu banyak
dependency yang tidak diperlukan
3. Mobile First

Mayoritas calon pelanggan kemungkinan mengakses dari smartphone.

Jadi desain dimulai dari:

Mobile
 ↓
Tablet
 ↓
Desktop
4. Conversion First

Setiap halaman harus mempunyai CTA yang jelas.

Contoh:

"Konsultasi & Info Layanan via WhatsApp"
